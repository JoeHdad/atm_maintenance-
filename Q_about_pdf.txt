7️⃣ Error Handling

If the PDF generation process fails:

Log the error message.

Mark the submission as "PDF generation failed".

Do not proceed with sending any email.

If the PDF generation succeeds but email sending fails (in Feature 4.6):

Log the failure.

Mark the submission as "Email failed".

8️⃣ Security Considerations

PDFs must not be publicly accessible without authentication.

Only authorized users (supervisors or admins with valid JWT tokens) can access or download the PDF.

No need to encrypt the file itself.
